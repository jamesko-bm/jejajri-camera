# 제자리 카메라 웹

접속 즉시 카메라 권한을 요청하고, 허용되면 후면 카메라를 우선 사용합니다.
일반 사용 화면에는 촬영·업로드·분석 버튼이 없습니다.

- 카메라 움직임 감지 → 노란 테두리 제거 → `확인 중`
- 약 1초간 안정된 장면 → 한국어/영어 OCR 자동 실행
- 두 개 이상의 비교 가능한 청구기호 → `완료`
- 인접한 두 책에서 청구기호가 감소하면 **감소하기 직전의 왼쪽 책**에 노란 테두리
- 읽지 못하면 완료로 처리하지 않고 3초 후 자동 재시도
- 움직임 이후 도착한 오래된 인식 결과는 폐기
- 카메라 연결 오류에만 복구 버튼 표시

예: `100 → 410 → 300 → 400`에서는 `410` 책을 표시합니다.
기존 Python v0.1의 최소 이동 알고리즘과 목적이 다릅니다.

영상·사진은 브라우저 내부 메모리에서 처리하며 녹화·서버 전송·저장하지 않습니다.
Tesseract.js 5.1.1 및 OCR 모델은 CDN에서 다운로드합니다.
카메라는 HTTPS 또는 localhost에서만 동작하며 최초 브라우저 권한 허용이 필요합니다.
모델 초기 다운로드/인식 속도는 단말과 네트워크에 따라 달라집니다.

## 검증

```powershell
node --test test.mjs camera.test.mjs
node --check dist/app.js
```

14개 자동 테스트 통과: 감소 직전 책 선택, 동률/권차, 자동 재시도,
느린 누적 이동, 노출 변화, 동시 처리 방지, 오래된 결과 폐기,
OCR 후보 생성/경계 보정, 업로드·조작 버튼 제거, 기존 정렬 로직.
로컬 브라우저에서 카메라 시작 요청과 단순화된 화면을 확인했습니다.
이 환경의 카메라 권한 대기로 실제 책장을 카메라로 비춘 종단 검증은 하지 못했습니다.

## 범위

책장 한 단을 정면으로 비추는 베타입니다. 책 영역은 OCR 위치와 세로 영상 경계로
추정하며 객체 탐지 모델에 의한 정확한 책 분할이 아닙니다.
읽어낸 청구기호끼리 비교하므로 OCR 누락·오인식에 따른 오탐/미탐이 가능합니다.
현장 도서관의 실제 촬영 정확도는 검증 전입니다.
분류번호·저자기호·권차를 비교하며 별치/복본 등 도서관 고유 규칙은 미지원입니다.

`dist/`만 정적 사이트로 배포합니다. Python Streamlit 소스는 이전 실험 버전으로 보존되어 있습니다.

## GitHub 및 Vercel 배포

이 `web/` 폴더를 저장소 루트로 사용합니다. `vercel.json`이 정적 출력 `dist/`와
카메라 권한 헤더를 지정합니다. 빌드 과정이나 서버 환경변수는 필요하지 않습니다.
Vercel에서 저장소를 연결할 때 Framework Preset은 Other, Output Directory는 dist입니다.
프로덕션 주소를 누구나 이용하려면 해당 프로젝트의 프로덕션 Deployment Protection이
공개 접속을 막지 않아야 합니다. 실제 배포 후 비로그인 접속을 검증해야 합니다.
GitHub 저장소와 Vercel 프로젝트는 연결된 계정에서 생성합니다.
배포 상태와 공개 주소는 실제 배포 완료 후 확인해야 합니다.
